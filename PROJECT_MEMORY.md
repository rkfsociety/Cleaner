# Память проекта Cleaner

## Назначение

Создать безопасный клинер для Windows.

## Принятые решения

- Приложение запускается обычным графическим `.exe` двойным кликом.
- Планируемая технология: C#/.NET 8 WPF.
- Публикация: автономная сборка `win-x64` в формате single-file, чтобы пользователю не требовалась отдельная установка .NET.
- Работа ведётся напрямую в ветке `main`.
- Новые ветки и pull request не создаются.

## План MVP

- Анализ временных файлов, кэшей и корзины.
- Предварительный показ найденных файлов и объёма.
- Выборочное удаление.
- Режим «только анализ» по умолчанию.
- Журнал действий и понятная обработка ошибок.

## Текущий статус

- Репозиторий создан и опубликован на GitHub.
- Создан первый WPF-интерфейс: боковая навигация, обзор состояния системы, карточки очистки, выбор категорий и история активности.
- Кнопка проверки сканирует `%TEMP%` текущего пользователя и `C:\Windows\Temp`, считает доступные файлы и их объём, не удаляя данные.
- Недоступные, занятые и символические каталоги пропускаются безопасно.
- Добавлена выборочная очистка найденных временных файлов с подтверждением пользователя.
- Пользовательский Temp выбран по умолчанию, системный Temp требует отдельного выбора; корзина пока отключена.
- Автономный exe собирается в `publish/win-x64/Cleaner.exe`.
