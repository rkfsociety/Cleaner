# Память проекта Cleaner

## Назначение

Создать безопасный клинер для Windows.

## Принятые решения

- Приложение запускается обычным графическим `.exe` двойным кликом.
- Планируемая технология: C#/.NET 8 WPF.
- Публикация: автономная сборка `win-x64` в формате single-file, чтобы пользователю не требовалась отдельная установка .NET.
- Работа ведётся напрямую в ветке `main`.
- Новые ветки и pull request не создаются.

## План MVP

- Анализ временных файлов, кэшей и корзины.
- Предварительный показ найденных файлов и объёма.
- Выборочное удаление.
- Режим «только анализ» по умолчанию.
- Журнал действий и понятная обработка ошибок.

## Текущий статус

- Репозиторий создан и опубликован на GitHub.
- Создан первый WPF-интерфейс: боковая навигация, обзор состояния системы, карточки очистки, выбор категорий и история активности.
- Кнопка проверки сканирует `%TEMP%` текущего пользователя и `C:\Windows\Temp`, считает доступные файлы и их объём, не удаляя данные.
- Недоступные, занятые и символические каталоги пропускаются безопасно.
- Добавлена выборочная очистка найденных временных файлов с подтверждением пользователя.
- Пользовательский Temp выбран по умолчанию, системный Temp и корзина требуют отдельного выбора.
- Корзина Windows теперь сканируется через Shell API и очищается только при явном выборе и подтверждении.
- Окно приложения зафиксировано в размере `1180x760`, изменение размера и внутренние скроллбары отключены.
- Вертикальная раскладка уплотнена, чтобы кнопка очистки помещалась в фиксированное окно; исправлен вывод количества файлов через `.Count`.
- Дополнительно уменьшена высота верхней карточки и внешние отступы по результатам визуальной проверки, чтобы кнопка очистки не обрезалась снизу.
- Добавлен диалог выбора фиксированных дисков; выбранные диски используются для сканирования и очистки их корзин.
- Добавлен просмотр деталей сканирования с объёмом, количеством и примерами найденных путей до очистки.
- Добавлен локальный журнал последних 20 очисток в `%LOCALAPPDATA%\Cleaner\history.json`.
- Пункт «История» теперь открывает окно со всеми сохранёнными операциями очистки.
- Индикатор свободного места в главной карточке и боковой панели рассчитывается по системному диску.
- Навигация подключена: «Очистка» запускает проверку, «Настройки» показывают режим и пути, «Помощь» объясняет порядок действий.
- Добавлена безопасная отмена длительного сканирования через кнопку «Отменить»; отмена не удаляет найденные данные.
- Выбор дисков теперь применяется к известным временным каталогам `Temp`/`Windows\Temp` и корзинам выбранных дисков; произвольный корень диска не сканируется.
- В пользовательскую категорию добавлено сканирование известных кэшей Chrome, Edge и Firefox; профили браузеров целиком не обходятся.
- После очистки карточки сбрасываются в состояние «требуется повторная проверка», чтобы не выдавать неподтверждённый объём; индикатор свободного места обновляется.
- Выбор дисков сохраняется между запусками в `%LOCALAPPDATA%\Cleaner\settings.json`.
- В диалоге дисков добавлены свободное место и кнопки «Выбрать все»/«Снять все».
- Добавлен `scripts/publish-windows.ps1` для воспроизводимой публикации автономного Windows `.exe`.
- Результат очистки содержит реальные значения удалённых файлов, пропущенных файлов и освобождённых байт; журнал сохраняет освобождённый объём, а не выбранный объём.
- Перед очисткой подтверждение показывает выбранный объём и предупреждает о запущенных Chrome, Edge или Firefox.
- Добавлена настройка безопасного режима: пропускать файлы Temp/кэшей младше 24 часов, с сохранением политики в `%LOCALAPPDATA%\Cleaner\policy.json`; корзина не фильтруется по возрасту.
- В окне истории добавлена отдельная подтверждаемая очистка `history.json` без удаления настроек дисков и политики.
- Сгенерирована и подключена иконка приложения `assets/cleaner-icon.ico`.
- Иконка в окне подключается через pack URI и встраивается как WPF Resource; это важно для single-file публикации.
- Приложение требует запуск от имени администратора через Windows-манифест и UAC.
- Автономный exe собирается в `publish/win-x64/Cleaner.exe`.
- Добавлено безопасное журналирование необработанных ошибок в `%LOCALAPPDATA%\Cleaner\app.log`; ошибка интерфейса также показывает понятное сообщение пользователю.
- Во время сканирования и очистки отображается индикатор активности и текущий этап с количеством уже найденных файлов и объёмом.
- Системный диск определяется через путь Windows, отмечается в выборе дисков и используется как единственный диск по умолчанию для новых настроек.
- Область сканирования ограничена разрешёнными каталогами: Temp, известные кэши Chrome/Edge/Firefox и корзина; корень диска и произвольные пользовательские папки не обходятся.
- Высота окна настроек увеличена до 450 px, чтобы статус администратора и системного диска не перекрывались кнопками; внутренние скроллбары не используются.
- В окне истории вертикальный скроллбар скрывается при небольшом количестве записей и включается автоматически только после 10 операций.
- Выравнивание флажка безопасного режима в окне настроек по вертикальному центру исправлено.
- Разметка окна истории переведена с DockPanel на фиксированные строки Grid, чтобы кнопка очистки истории не растягивалась в вертикальную полосу.
- Очистка корзины теперь выполняется и учитывается по каждому диску отдельно; уже пустая корзина не считается ошибкой, а частичный сбой на одном диске не списывает успешно удалённые файлы на других дисках в пропущенные.
- Сканирование системных Temp-файлов сужено до фактического системного диска; папка `<Диск>:\Temp` на прочих выбранных дисках больше не сканируется как системный мусор.
- Добавлен проект `Cleaner.Tests` (xUnit) с юнит-тестами политики безопасного возраста и логики отбора/удаления файлов; добавлен GitHub Actions workflow, собирающий проект и прогоняющий тесты на каждый push и pull request в `main`.
- Все флажки главного окна, настроек и выбора дисков выровнены по вертикальному центру с нулевым лишним внутренним отступом.
