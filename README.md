# Cleaner

Windows-клинер с графическим интерфейсом и запуском через автономный `.exe`.

## Запуск

Готовый файл находится в `publish/win-x64/Cleaner.exe`. Обычная проверка и очистка пользовательских данных не требуют запуска от имени администратора. Системные файлы, к которым нет доступа, безопасно пропускаются.

## Возможности

- сканирование Temp и известных кэшей Chrome, Edge и Firefox;
- список установленных программ с сортировкой по давности использования;
- выбор фиксированных дисков и проверка их корзин;
- предварительный просмотр найденных данных;
- выборочная очистка с подтверждением;
- отчёт об удалённых и пропущенных файлах;
- история последних операций.

## Установленные программы

Раздел «Программы» показывает установленное ПО из реестра Windows (для всех пользователей и для текущего, в 64- и 32-битном представлении). Для каждой программы выводятся издатель, примерный объём, дата установки, дата последнего запуска и простой в днях.

Дата последнего запуска берётся из журнала запусков Windows: `UserAssist` текущего пользователя и папка `Prefetch` (доступна не всегда). Если запуск найти не удалось, показывается дата установки, а при её отсутствии — «нет данных»; источник указан в отдельной колонке. Программы без данных о запуске всегда идут в конце списка, чтобы их не приняли за давно забытые.

Доступны поиск, сортировка (давно не использовались, недавно использовались, по объёму, по дате установки, по названию) и фильтр по простою от 30 до 365 дней. Cleaner ничего не удаляет из этого списка: удаление программ открывается в стандартном окне Windows.

## Безопасность

- по умолчанию выполняется только анализ;
- очистка возможна только для результата проверки не старше пяти минут;
- перед удалением путь повторно проверяется: он должен оставаться внутри разрешённого каталога и не содержать ссылок/junction;
- системный Temp открывается отдельной повышенной сессией, в которой пользовательские данные и корзина отключены;
- файлы младше 24 часов можно не удалять в настройках;
- очистку можно отменить; уже удалённые файлы не восстанавливаются;
- корзина очищается целиком только на явно выбранных дисках и после отдельного подтверждения.

## Сборка автономного exe

Из корня проекта выполните:

```powershell
.\scripts\publish-windows.ps1
```

Скрипт сам восстанавливает зафиксированные зависимости для `win-x64` и создаёт автономный single-file `.exe`.
